# 分阶段发布计划

当前版本提供独立的外围工具和合成演示。研究核心尚未公开，不应将当前版本表述为完整模型实现或可复现论文的代码。

## 当前阶段

公开内容包括：

- JSON 数据校验；
- 检测结果的 reference AP 评估；
- SVG 可视化；
- 合成图像、合成标注与合成预测；
- 外围工具的测试、文档和示例接口。

训练与推理入口目前明确报告未实现，不调用隐藏模型，不提供替代模型结果。合成预测也不是研究模型生成的输出。

## 后续阶段

计划在论文录用并完成整理后发布研究核心。后续将通过实际文件、版本说明和运行说明明确可用范围；未发布的功能不能从当前接口推断为可用。

当前版本没有承诺核心模型的运行效果，也没有承诺复现论文结果。模型、训练、推理与权重是否已经公开，应以对应版本的实际发布内容为准。

## 许可范围

当前包的 MIT 许可仅覆盖包内实际提供的文件。未包含的研究核心不在此次发布与许可范围内。后续核心发布时，将同时明确其许可与使用说明。
